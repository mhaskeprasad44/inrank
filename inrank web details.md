## 2. Technical Stack & Web Architecture

* **Frontend Engine**: Vite + Modern TypeScript (ESM)
* **Styling & Design System**: Tailwind CSS utility design system with custom light & dark theme states, high-contrast typography and zero-layout-shift micro-interactions.
* **Typography**: Plus Jakarta Sans & Inter (body text), Playfair Display & Syne (headings & brand accents).
* **Iconography**: Lucide React / Modern SVG Icons.
* **Client-Side Routing**: Hash-based single-page navigation (`/#/`, `/#/services`, `/#/service/:id`, `/#/blog`, `/#/blog/:slug`, `/#/about-us`, `/#contact`).
* **Structured Data Graph**: Automated dynamic `JSON-LD` schemas injecting `Organization`, `WebPage`, `BlogPosting`, `Service`, `FAQPage` and `BreadcrumbList`.
