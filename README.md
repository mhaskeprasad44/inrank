## 🚀 Overview

This repository hosts the production source code for **Inrank Technologies 2.0** ([https://inranktech.com](https://inranktech.com)). Built with a clean, high-performance static architecture delivering sub-second load times, strict semantic HTML hierarchy, and zero skipped headings.

### Key Capabilities
- **27 Specialized Capability Pages**: Complete service architecture covering Web Engineering, Search Optimization, Paid Media, and Strategic Branding.
- **AI Answer Engine & GEO Ready**: Complete manifests (`/llms.txt`, `/llms-full.txt`, semantic Schema.org JSON-LD graph) optimized for Google AI Overviews, ChatGPT Search, and Perplexity AI citations.
- **Dual-Tier Resilient Contact Form**: High-deliverability inquiry dispatch via Hostinger PHP engine with cross-origin fallback, anti-spam honeypot, and instant WhatsApp chat routing.
- **Enterprise Core Web Vitals**: Modern WebP assets, native SVG branding, lazy loading, and sub-1.2s First Contentful Paint.
